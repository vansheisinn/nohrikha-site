# Nohrikha: устройство сайта

Поддерживаются только русский и английский языки: RU — корень сайта, EN — `en/`. В каждой версии пять страниц: `index.html`, `stories.html`, `timeline.html`, `contact.html`, `psovaya-ohota.html`. Переключатель RU / EN сохраняет выбранную страницу и работает без JavaScript. Относительные ссылки и ресурсы работают с корня и из `/nohrikha-site/`. Бывшие технические DE/KZ разделы удалены по решению владельца; их содержимое доступно в истории Git.

Утверждённое тёплое оформление — `styles.css`, навигация — `main.js`. Исходная иллюстрация встроена в главные страницы. Google Fonts имеют резервные системные шрифты. Дизайн, исторические тексты и контактная форма сохраняются.

По решению владельца от 16 октября 2026 г. индексация разрешена: все 10 страниц содержат `index, follow`. `robots.txt` разрешает обход и объявляет `https://nohrikha.com/sitemap.xml`; карта сайта содержит все действующие RU/EN страницы. Поисковые системы самостоятельно определяют сроки обхода и включения страниц в поиск.

## Предпросмотр ссылок

Все 10 страниц содержат статические Open Graph и Twitter Card метаданные. Заголовок и описание соответствуют выбранной странице, обложка — языку RU/EN. Telegram и WhatsApp получают JPEG по абсолютному HTTPS URL `https://nohrikha.com/assets/share/nohrikha-ru-v1.jpg` или `nohrikha-en-v1.jpg`. Это отдельные файлы 1200×630, размером менее 300 КБ: встроенная в HTML иллюстрация сама по себе не даёт мессенджерам адрес картинки.

Обложки повторяют существующие иллюстрацию, логотип, цвета и заголовок главной страницы. Для необязательной пересборки: `python3 scripts/build_share_images.py` (только разработчику нужны Python Playwright и Chromium). Сайт использует готовые JPEG без сборки и JavaScript. При замене обложки менять версию в имени файла и метаданных, чтобы не получать старую картинку из кэша.

После слияния и завершения GitHub Pages проверить публичные URL картинок и заново отправить ссылку в мессенджере. Старые карточки могут сохраняться в кэше; в Telegram можно запросить обновление через `@WebpageBot`. Реальный внешний предпросмотр проверяется после публикации: локальная проверка не подтверждает обновление кэша WhatsApp или Telegram.

## Счётчик посещений

Собственный счётчик Cloudflare Workers + D1 подключён в PR №20; владелец подтвердил работу 19 октября. `counter-config.js` использует `https://nohrikha-counter.vansheisinn.workers.dev`. Посещения собираются на всех 10 страницах. По обновлённому решению владельца раскрывающийся блок статистики выводится только внизу RU/EN страниц контактов: текст совпадает с фоном футера и читается при выделении, линии и стрелка блока убраны. Нажатие на строку раскрывает приблизительное число браузеров сегодня, все просмотры, неделю по дням и источники за 30 дней. Изменение отображения передаётся владельцу отдельной веткой для ручного слияния. В D1 только числовые агрегаты; в localStorage только дата. При пустом `endpoint` счётчик полностью отключён. Код счётчика и его ошибки не влияют на форму, навигацию и SEO. Условия бесплатности и ссылки с метками — `COUNTER_SETUP.md`.

## Контакты

На каждой странице есть https://t.me/nohrikha. Форма работает через Formspree; имя и email обязательны по решению владельца. Владелец подтвердил Free (50 обращений/месяц), включённые Formshield/CAPTCHA и успешную тестовую отправку. Из тестов сообщения во внешний сервис не отправляются. Подробности — `CONTACT_SETUP.md`.

## Литературное произведение

Обе страницы `psovaya-ohota.html` содержат полный авторский русский текст с разрешения Жанны Дроздовской. На EN странице вступление английское, сам оригинал — русский (`lang="ru"`). Исходник — `content/psovaya-ohota.ru.txt`; после согласованной правки выполнить `python3 scripts/build_play.py`. `python3 scripts/build_play.py --check` проверяет актуальность страниц. Для посетителя сборка и JavaScript не нужны.

## Проверка и публикация

Из корня проекта: `python3 checks/check_site.py`, `python3 checks/check_editorial.py`, `python3 scripts/build_play.py --check`. Для браузерных проверок с Playwright/Chromium: `python3 checks/check_contact_browser.py`, `python3 checks/check_editorial_browser.py`. Локальный сервер: `python3 -m http.server 8000 --bind 127.0.0.1`.

Перед каждой новой задачей Codex сохраняет проверенный ZIP актуального main и отправляет резервную метку в GitHub. Затем готовит и проверяет отдельную ветку; владелец вручную создаёт и объединяет PR. При Pages из main слияние запускает обновление сайта. DNS и CNAME менять только по отдельному решению владельца. Зарегистрированные домены: nohrikha.com — основной, nohrikha.org — для перенаправления на .com. Файл CNAME добавлен владельцем через GitHub Pages. Canonical, og:url, hreflang и sitemap направлены на https://nohrikha.com. Решение об открытии индексации зафиксировано в разделе 15 PROJECT_BRIEF.md.

После слияния PR проверить опубликованные страницы и `https://nohrikha.com/robots.txt`. Для отправки карты сайта владелец добавляет `https://nohrikha.com/` в Google Search Console и Яндекс Вебмастер, подтверждает права выбранным способом и указывает `https://nohrikha.com/sitemap.xml`. Учётные записи и подтверждения прав не создаются автоматически; секреты и личную почту в репозиторий не добавлять. Дополнительное изменение DNS требует отдельного решения владельца.
