# Nohrikha: устройство сайта

Поддерживаются только русский и английский языки: RU — корень сайта, EN — `en/`. В каждой версии пять страниц: `index.html`, `stories.html`, `timeline.html`, `contact.html`, `psovaya-ohota.html`. Переключатель RU / EN сохраняет выбранную страницу и работает без JavaScript. Относительные ссылки и ресурсы работают с корня и из `/nohrikha-site/`. Бывшие технические DE/KZ разделы удалены по решению владельца; их содержимое доступно в истории Git.

Утверждённое тёплое оформление — `styles.css`, навигация — `main.js`. Исходная иллюстрация встроена в главные страницы. Google Fonts имеют резервные системные шрифты. Дизайн, исторические тексты и контактная форма сохраняются.

Все 10 страниц содержат `noindex, nofollow, noarchive`. `robots.txt` позволяет обход для чтения noindex; sitemap содержит все действующие RU/EN страницы. Noindex не ограничивает доступ по ссылке.

## Контакты

На каждой странице есть https://t.me/nohrikha. Форма работает через Formspree; имя и email необязательны. Владелец подтвердил Free (50 обращений/месяц), включённые Formshield/CAPTCHA и успешную тестовую отправку. Из тестов сообщения во внешний сервис не отправляются. Подробности — `CONTACT_SETUP.md`.

## Литературное произведение

Обе страницы `psovaya-ohota.html` содержат полный авторский русский текст с разрешения Жанны Дроздовской. На EN странице вступление английское, сам оригинал — русский (`lang="ru"`). Исходник — `content/psovaya-ohota.ru.txt`; после согласованной правки выполнить `python3 scripts/build_play.py`. `python3 scripts/build_play.py --check` проверяет актуальность страниц. Для посетителя сборка и JavaScript не нужны.

## Проверка и публикация

Из корня проекта: `python3 checks/check_site.py`, `python3 checks/check_editorial.py`, `python3 scripts/build_play.py --check`. Для браузерных проверок с Playwright/Chromium: `python3 checks/check_contact_browser.py`, `python3 checks/check_editorial_browser.py`. Локальный сервер: `python3 -m http.server 8000 --bind 127.0.0.1`.

Codex готовит и проверяет ветку; владелец вручную создаёт и объединяет PR. При Pages из main слияние запускает обновление сайта. DNS, CNAME и индексацию менять только по отдельному решению владельца. Зарегистрированные домены: nohrikha.org — основной, nohrikha.com — для будущего перенаправления.
