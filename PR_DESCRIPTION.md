Убирает слово «неграмотной» из заключительной фразы рассказа Жанны: «В письме Жанна назвала её акушеркой с золотыми руками и сердцем». В EN убрано соответствующее illiterate и согласован артикль: «a midwife with golden hands and a kind heart».

Остальные абзацы, исторические сведения и текст пьесы сохранены. Контрольные суммы этих двух абзацных наборов обновлены после проверки исходных утверждённых значений. Проверки: python3 checks/check_editorial.py, python3 checks/check_site.py, git diff --check. Слияние выполняет владелец.
