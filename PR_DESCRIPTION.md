Обновляет семейные истории RU/EN по утверждённому редакционному пакету и публикует предоставленный владельцем полный русский текст пьесы «Псовая охота» Жанны Дроздовской.

- В рассказах восстановлены авторская атрибуция и имена Куртукова, Павел Чернов, Ирина Петровна Островная. Из обоих рассказов на каждом языке есть контекстная ссылка на литературную страницу.
- На psovaya-ohota.html и en/psovaya-ohota.html размещён один и тот же русский оригинал целиком: 3 действия, 8 явлений, все реплики и ремарки до «Занавес». Английская страница явно помечена Original text in Russian. Художественный перевод не создавался.
- Исходник хранится отдельно: content/psovaya-ohota.ru.txt. Автоматических исправлений и сокращений нет; сохранены переносы строк, пробелы и авторская пунктуация. scripts/build_play.py встраивает текст в обе статические страницы без зависимости от JS или внешнего сайта. При правке исходника выполнить python3 scripts/build_play.py, затем python3 scripts/build_play.py --check.
- На литературных страницах есть ссылки по действиям, возврат к обоим рассказам, автор, жанр, год, разрешение, © Жанна Дроздовская, 2016, первоисточник и свидетельство №116072602762. Canonical/hreflang/OpenGraph и sitemap обновлены с сохранением текущего базового адреса.
- На главной и в хронологии уточнена атрибуция. Неопределённость встречи деда с Нохрихой сохранена. Персонажи пьесы не перенесены в документальную хронологию.

Проверки: python3 checks/check_site.py (18 страниц, ссылки/якоря/языки, исходная иллюстрация и noindex); python3 checks/check_editorial.py (все утверждённые абзацы, имена, отсутствие частных email/телефонных ссылок, полное посимвольное совпадение обоих HTML с исходником пьесы); python3 scripts/build_play.py --check; python3 checks/check_editorial_browser.py (48 раскладок при 1440/375/320 px, RU/EN, корень и подпуть GitHub Pages, переходы рассказ ↔ пьеса, переключатель языков, исходный текст в DOM, размеры 22/20 px и сохранение переносов); git diff --check.

Источник полного текста — сообщение владельца в этом задании, предоставленное после отказа Стихи.ру HTTP 403. Новая загрузка первоисточника не требовалась. Разрешение на публикацию подтверждено владельцем и редакционным пакетом. Полные письма, PDF, редакционный ZIP и частные контакты в репозиторий не добавлялись.

Сохранены тёплый семейный дизайн, форма, Telegram, DE/KZ, существующие canonical URL и noindex. Изменения не публиковались автоматически; слияние выполняет владелец.
