# Nohrikha / Нохриха

Первая техническая версия международного историко-генеалогического проекта. Статический HTML/CSS/JavaScript: без сборки, платных сервисов, внешних шрифтов, аналитики или обязательных зависимостей.

## Просмотр

Откройте `index.html` в браузере; другие версии — `en/index.html`, `de/index.html`, `kz/index.html`. Либо из корня проекта выполните `python3 -m http.server 8000` и откройте `http://localhost:8000/`. Переключатель RU / EN / DE / KZ работает без JavaScript. При смене языка данные формы не сохраняются.

## Что реализовано

- Русская, английская, немецкая и казахская страницы, адаптивное оформление, клавиатурная навигация.
- Описание проекта, цели, пустые разделы хронологии и материалов без выдуманных исторических сведений.
- Форма для подготовки локального `.txt`-черновика. Отправки, серверной обработки и загрузки документов нет. Анонимный режим исключает поля имени и email из файла; личные сведения в самом тексте посетитель должен убрать самостоятельно. Текст не записывается в localStorage/cookies и не передаётся сайтом. Браузер может управлять собственным восстановлением полей.
- `noindex, nofollow, noarchive` на всех четырёх страницах. Это просьба поисковикам, а не защита доступа; публичный репозиторий доступен всем.

## Публикация на GitHub Pages

1. Утвердить содержание и объединить Pull Request в `main`.
2. В репозитории открыть **Settings → Pages → Build and deployment**.
3. Выбрать **Deploy from a branch**, ветку `main`, папку **/(root)** и сохранить.
4. После успешного развёртывания сайт будет доступен по адресу `https://vansheisinn.github.io/nohrikha-site/`, языковые версии — `/nohrikha-site/en/`, `/nohrikha-site/de/`, `/nohrikha-site/kz/`.

Все пути к ресурсам относительные: сайт работает как в `/nohrikha-site/`, так и в корне будущего собственного домена. `.nojekyll` отключает обработку Jekyll. Автоматическая публикация в этом PR не настраивается.

## Собственный домен — позже

После выбора и самостоятельного подключения домена укажите его в **Settings → Pages → Custom domain**, настройте DNS по документации GitHub Pages, подтвердите домен и включите **Enforce HTTPS**. GitHub создаст файл `CNAME`; сохранить его в репозитории. Сейчас `CNAME` и фиктивные canonical URL намеренно отсутствуют. Домен не приобретался.

## Перед публичным сбором информации

Согласовать содержание, контактный канал, правила обработки персональных данных и разрешения на публикацию материалов. Подключить и проверить реальную отправку отдельным изменением, затем заменить предупреждение о недоступной отправке. Не публиковать частные сообщения и документы в GitHub Issues/PR. Удалить `noindex` со всех четырёх страниц только после утверждения окончательного содержания и готовности реальной формы связи; до этого сохранять его и при публикации временной версии.

## Проверка

`node --check assets/app.js` — синтаксис JavaScript. `python3 checks/check_site.py` — локальные ссылки, языки, метаданные и отсутствие внешних ресурсов. `node checks/check_form.cjs` — поведение анонимного черновика, валидация, предотвращение отправки.

Файлы `checks/` нужны только для разработки. Для сайта не требуются Node.js или Python. Все публичные тексты редактируются непосредственно в HTML; исторические материалы добавлять с источниками и после согласования.

Языки: `ru` — русский, `en` — английский, `de` — немецкий, `kk` — стандартный HTML-код казахского языка (кириллица); посетители видят **KZ**, адрес раздела — `/kz/`. Переводы технической версии являются черновыми; перед публикацией окончательного содержания нужна редакторская проверка.
