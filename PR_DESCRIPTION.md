Убирает полосу «Черновик» со всех 16 страниц и редакционные пометки из заголовков/описаний DE/KZ. Удалён неиспользуемый CSS уведомления. Сохраняет увеличенный текст, исторические материалы, навигацию, Telegram и работающую форму с антиспамом.

Noindex сохранён: очистка интерфейса не включает поисковую индексацию. DE/KZ продолжают показывать исторические тексты на английском с lang=en; это не завершённые переводы. DNS и домены не менялись.

Проверки: 16 страниц, языки, ссылки и якоря, сохранность исторического содержания, синтаксис JS; браузерные проверки раскладок и формы с подменённым обработчиком. Слияние выполняет владелец; Pages из main затем обновит сайт.
